# From Coverage to Worst-Case Error Bounds: Space-Filling Excitation Design

Code, settings and a demo for the paper

> M. Herkersdorf, O. Nelles and K. A. Prajapati,
> *From Coverage to Worst-Case Error Bounds: Space-Filling Excitation Design*,
> submitted to the IFAC Symposium on System Identification (SYSID).

University of Siegen, Automatic Control and Mechatronics.

> **Status:** The code is being prepared for release and will be available in this repository by 4th December 2027.

## Contents (from 16 November 2026)

- MATLAB implementation of the receding-horizon (RHC) space-filling excitation design with the
  criterion proposed in the paper.
- Settings of both studies: the Duffing oscillator (Sec. 4) and the Bouc–Wen benchmark (Sec. 5).
- A demo of the RHC design:
  - Duffing oscillator: the input and state trajectories and the distribution of the samples in the
    joint input–state space;
  - Bouc–Wen benchmark: the excitation signals.

## Related work

The design builds on the RHC framework of

> M. Herkersdorf and O. Nelles, *Online and offline space-filling input design for nonlinear system
> identification: A receding horizon control-based approach*, American Control Conference (ACC), 2026.
